# The denominator for `bun run css-coverage`.
#
# ROADMAP A1 says Tailwind defines dziri's CSS subset. This is that subset
# expressed as CSS *properties* — the properties Tailwind's utilities generate —
# because a percentage needs a property list, not a utility list. `p-4`, `p-6`
# and `p-8` are three utilities and one property.
#
# Curated, not derived: Tailwind is not a dependency here. Every name below is
# validated against mdn-data by the script, so a typo or an invented property is
# a hard error rather than a silently depressed score.
#
# Committed non-goals are absent by construction: no floats, tables, writing
# modes, fragmentation, multi-column or print. Edit freely — this file is the
# scope decision, and it is meant to be argued with.
